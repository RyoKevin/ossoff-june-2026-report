# 奥索夫六月捐款中的27美元突增

**两天集中了全月近63%的27美元交易，6月30日占比达到此前的4.87倍，增长遍及50州及华盛顿特区。**

2026年10月20日 · 基于美国联邦选举委员会（FEC）公开申报的交易统计

## 核心发现

2026年6月29—30日，Jon Ossoff（乔恩·奥索夫）的ActBlue捐款记录出现一次鲜明的全国性金额变化：**27美元交易占比从此前28天的1.10%，跃升至连续两天超过5%。**同期，其他2,146个可识别联邦收款委员会合计的27美元占比下降。

这波增长具备三个相互衔接的特征：**金额集中、地域广泛、持续时间短。**最后两天的27美元交易对应3,296个捐款人代理，其中59.44%有此前其他金额记录、没有27美元历史；七月继续向奥索夫捐款的981个代理中，86.54%未再使用27美元。

**数据揭示的是一次发生于季末募款期间、集中体现于奥索夫的短期金额选择变化。**结合全国同步增长与后续金额转换，机制推断指向当期募款中的特定金额请求、表单设置或加额提示；具体触发渠道仍待来源标识与历史表单配置对应。

6月30日的27美元占比为前28天基线的 **4.87倍**，提高 **4.26个百分点**。在50州及华盛顿特区，各地当天占比均高于自身前28天基线；在固定20个大样本州，29日和30日均高于各自基线。[全国及各州汇总数据](evidence/national.json)

## 27美元是一批捐款人的短期金额选择

最后两天的3,311笔27美元交易，合并为3,296个姓名邮编代理。回查2026年3月起、截至每个代理本次首次27美元交易前一天的记录，得到以下互斥分类：

| 可见捐款历史 | 代理数 | 占比 |
|---|---:|---:|
| 有其他金额历史，没有27美元历史 | 1,959 | 59.44% |
| 曾向可识别收款方捐过27美元 | 253 | 7.68% |
| 回查窗口内未匹配到既往记录 | 1,084 | 32.89% |
| **合计** | **3,296** | **100%** |

其中，此前向奥索夫捐过27美元的为 **94个，占2.85%**。七月仍向奥索夫捐款的981个代理中，132个继续出现27美元记录，**849个只出现其他金额，占七月回流者的86.54%**。

这些记录呈现出明确的时间结构：六月末集中选择27美元，随后多数回流者转向其他金额。按完整姓名与地址采用更严格匹配，月底27美元代理数仍为3,296，历史构成结论保持稳定。[历史与七月后续数据](evidence/donor_history.json)

## 增长广泛分布于邮编和城市

佛州6月30日首次进入当月记录的1,734个代理，分布在 **641个邮编**。其中110个27美元代理分布在 **95个邮编**，单个邮编最多3个。

按邮政城市名称近似归入迈阿密戴德的组别，仅占这110个代理中的 **4个**。剔除该组后，佛州27美元占比仍从6月1—29日的 **1.19%**上升至30日的 **6.33%**。

这一地理分布与全国各州同步上升相呼应：**27美元主峰具有跨地域扩散特征。**[地理汇总数据](evidence/geography.json)

## 得州与佛州的精确接近集中在六月自然月口径

六月的另一项突出结果，是得州、佛州与弗吉尼亚州的月内复捐率高度接近。复捐率定义为当月至少两笔交易的代理数，占当月至少一笔交易代理数的比例。

| 州 | 六月交易笔数 | 代理数 | 至少两笔的代理数 | 月内复捐率 |
|---|---:|---:|---:|---:|
| 得州 TX | 9,449 | 7,684 | 1,206 | 15.69495% |
| 佛州 FL | 13,719 | 11,317 | 1,774 | 15.67553% |
| 弗吉尼亚 VA | 6,423 | 5,255 | 824 | 15.68030% |

得州与佛州只差 **0.01942个百分点**，在20州190组配对中排第4近；统一常用金额分组下，金额分布相似度排第5。其他13个委员会、49个候选人月份的1,316组州对观察中，原分组下同时达到两项阈值的观察数为零。这些是共享州和月份的对照观察，具有相互依赖性。[州际与跨候选人数据](evidence/state_comparison.json)

**这种突出程度随金额分组与日期边界变化。**将18美元、36美元单列后，得州—佛州金额相似排名为第52/190；其他候选人有7组达到细分口径的双重阈值。18美元交易得州7笔、佛州58笔，36美元分别2笔、38笔。

相同长度的30天窗口，得到以下复捐率差距：

| 窗口 | 得州与佛州复捐率差 |
|---|---:|
| 5月31日—6月29日 | 0.21356个百分点 |
| **6月1日—6月30日** | **0.01942个百分点** |
| 6月2日—7月1日 | 0.18427个百分点 |

六月起点前后7天的15个窗口中，只有六月本身同时达到原参照的两项阈值。末日前后的人群变化为这次靠拢提供了直接计数解释：6月30日，得州与佛州分别新增1,250、1,734个当月首次出现的代理；此前单笔、当天转为复捐的分别为222、308个。这些分子与分母的变化共同推动了整月比例收敛。[窗口与末日计数](evidence/state_comparison.json)

## 结论

**六月29—30日，奥索夫的27美元捐款形成了一次集中、全国性、短期的金额增长：两天承载全月近63%的该金额交易，6月30日占比达到此前的4.87倍。**同期其他收款委员会合计占比下降，既往与后续捐款记录又显示这批人群大多没有持续使用27美元。

由此形成的机制推断是：**季度末集中募款叠加了奥索夫相关的短期金额引导。**公开记录已定位到六月募款表单 `ossoff-em-jun26`；交易来源参数与当时金额配置，是将这一推断落实到具体渠道的识别依据。[表单与公开来源记录](evidence/public_sources.json)

州际结果则显示，得州与佛州的精确重合集中于六月自然月及常用金额分组。金额细分、相邻日期窗口和月底人群变化，共同界定了这一现象的实际范围。
